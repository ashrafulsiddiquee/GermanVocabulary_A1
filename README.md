# Deutsch A1 Vokabeln

An interactive, single-page German **A1 vocabulary trainer** with 1,000+ words and example sentences, organised by course lesson (Lektion 1–14 plus classroom words). Runs entirely in the browser: no backend, no build step, no dependencies.

## Features

- **Flashcards**: flip cards, shuffle, pick a lesson, Deutsch ↔ English, mark words as known, audio pronunciation
- **Words by category**: every lesson with plural forms, translations, example sentences, search and colour-coded *der / die / das*
- **Quiz**: multiple choice in both directions, 10 / 20 / all questions, retry missed words
- **Hardest words**: words you miss are collected and can be drilled as flashcards or a quiz

## Keyboard shortcuts

- Flashcards: `Space` flip, `←` / `→` previous / next
- Quiz: `1`–`4` choose an answer, `Enter` / `Space` next question

## Data

The vocabulary comes from the *Deutsch Vocabulary – A1* course list. It was extracted automatically, so please report any typos.
